# Automation Blueprints

These YAML automations are ready to import into Home Assistant once the relevant
hardware and integrations are set up. Each file is a standalone automation that
can be pasted into `configuration.yaml` or imported via the UI.

## Files

| File | Requires | Wow Factor |
|------|----------|------------|
| `welcome-home.yaml` | Presence detection (phone/mmWave) | ⭐⭐⭐⭐⭐ |
| `adaptive-lighting.yaml` | Smart bulbs (any) | ⭐⭐⭐⭐ |
| `movie-mode.yaml` | Smart lights + media player | ⭐⭐⭐⭐⭐ |
| `goodnight-routine.yaml` | Lights + locks + thermostat | ⭐⭐⭐⭐ |
| `presence-aware-rooms.yaml` | Aqara FP2 mmWave sensors | ⭐⭐⭐⭐⭐ |
| `weather-reactive-home.yaml` | Weather integration + lights | ⭐⭐⭐ |
